# 三国演义

本仓库收录《三国演义》一百二十回正文，并提供可交互的全人物、全地点和全官职可视化：

- 双击打开 [`三国演义标注版电子书.html`](./三国演义标注版电子书.html)，阅读全本正文；人物、地点和官职均有颜色标记，点击即可查看档案并跳转至对应完整可视化。
- 双击打开 [`三国演义人物可视化.html`](./三国演义人物可视化.html)，可按登场顺序或出现次数浏览、搜索和筛选人物。
- 点击人物可查看人物档案、一百二十回出场轨迹，以及带段落上下文、按原著位置排序的全部事件。
- 点击出场轨迹中的红色回目柱可只看该回事件，再次点击同一回即可恢复全部事件。
- 事件段落中的其他人物姓名和别称带有虚线下划线，点击可直接跳转到对应人物档案。
- 双击打开 [`三国演义地点可视化.html`](./三国演义地点可视化.html)，可以相同方式浏览全书州郡、城池、关隘、山川和建筑地点。
- 双击打开 [`三国演义官职可视化.html`](./三国演义官职可视化.html)，可浏览正文中的中枢、文官、地方与军事职任，并查看逐回轨迹和全部相关事件。
- [`data/三国演义人物数据.json`](./data/三国演义人物数据.json)、[`data/三国演义地点数据.json`](./data/三国演义地点数据.json) 和 [`data/三国演义官职数据.json`](./data/三国演义官职数据.json) 保存可复核的结构化统计结果。

重新生成数据和网页：

```powershell
python .\tools\extract_characters.py
python .\tools\extract_locations.py
python .\tools\extract_offices.py
python .\tools\build_ebook.py
```

出现次数以正文中人物姓名、地点名称、正式官职及其明确别称的实际出现为准；官职统计排除爵位、亲属身份和一般尊称，事件文本和位置全部取自 `src/` 下的本书正文。
